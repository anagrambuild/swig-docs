## Introduction

The Developer SDK connects your server to Swig’s hosted wallet services. Use it
to create wallets, assign permissions, query balances and activity, and prepare
financial operations. TypeScript, Python, and Rust clients share a preparation
model: your application authorizes, signs, and confirms transactions.

## Examples

### Install the SDK

Install the latest published package for your server language.

<CodeGroup>
```bash TypeScript
bun add @swig-wallet/developer-sdk
```
```bash Python
pip install --upgrade swig-developer-sdk
```
```bash Rust
cargo add swig-developer-sdk
```
</CodeGroup>

### Query an existing wallet

With a configured client and the wallet’s configuration address, fetch its holdings.

<CodeGroup>

```typescript TypeScript
const wallet = swig.wallets.use(swigConfigAddress);
const balances = await wallet.listTokenBalances();
```

```python Python
wallet = swig.wallets.use(swig_config_address)
balances = await wallet.list_token_balances()
```

```rust Rust
let balances = wallet.list_token_balances(&swig_config_address).await?;
```

</CodeGroup>

## Errors

| Error | Meaning |
| :--- | :--- |
| Authentication failed | The configured API key is missing, invalid, expired, or revoked. |
| Operation unavailable | Language support differs. Each guide shows supported languages and labels unpublished features. |
| Usage cap reached | API and DEX allowances are separate; see [Pricing & quotas](/query). |
