Swig gives applications programmable wallets with scoped permissions. Start with
one of four integration areas, then follow its setup and wallet guides.

## Developer SDK

Prepare wallet operations, read balances, and sponsor signed transactions from
a trusted TypeScript or Python server. The REST API reference lives here too.

[Start with the Developer SDK →](/developer-sdk)

## Solana Protocol SDK

Build and sign Solana wallet transactions directly in TypeScript or Rust.
Learn the account, permission, and execution models as you build.

[Start with the Solana Protocol SDK →](/solana)

## EVM Protocol SDK

Create wallets, assign roles, and send direct or sponsored transfers using the
source-available TypeScript, Rust, and Python SDKs.

[Start with the EVM Protocol SDK →](/evm)

## IdP

Add OAuth or OTP sign-in to a web or mobile app, then use the resulting Swig
session in your wallet integration.

[Start with IdP →](/idp-sdk)
