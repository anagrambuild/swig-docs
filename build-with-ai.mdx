## Introduction

MCP gives an AI assistant tools and context for Swig. Use Docs MCP to find
current integration guidance, or run Wallet MCP locally when the assistant needs
to inspect wallets and prepare operations.

## Examples

### Connect Docs MCP

Add the hosted documentation server to your assistant. For Claude Code:

```bash
claude mcp add --transport http swig-docs https://build.onswig.com/mcp
```

### Build Wallet MCP

Install Bun and Node.js, then build the wallet tool server.

```bash
git clone https://github.com/anagrambuild/swig-ts.git
cd swig-ts
bun install
bun run build
```

### Connect Wallet MCP

Add this entry to your MCP client, using the absolute path to the built checkout.

```json
{
  "mcpServers": {
    "swig-wallet": {
      "command": "node",
      "args": ["/absolute/path/to/swig-ts/packages/mcp-server/dist/index.js"]
    }
  }
}
```

### Verify the connection

Open the assistant’s tools list, then ask it to locate the wallet-creation guide.

```text
Find the Developer SDK wallet-creation guide.
Show the inputs and supported signing options.
```

## Input

| Server | Input |
| :--- | :--- |
| Docs MCP | Remote HTTP URL `https://build.onswig.com/mcp`; no API key. |
| Wallet MCP | Local built entrypoint and the intended network’s RPC configuration. Start with [Wallet MCP setup](/tutorials/mcp). |
| Wallet authority | Grant the agent only the [permissions](/developer-sdk/permissions) needed for its task; review prepared actions before signing. |

## Output

| Connection | Expected result |
| :--- | :--- |
| Docs MCP | Documentation search tools are available in the assistant. |
| Wallet MCP | `configure_rpc` and `fetch_swig_wallet` appear; configure the network before wallet calls. |
| Text-only integration | [llms.txt](https://build.onswig.com/llms.txt) lists pages; [llms-full.txt](https://build.onswig.com/llms-full.txt) contains the combined documentation. |

## Errors

| Error | Meaning |
| :--- | :--- |
| Server not found | The local entrypoint path is incorrect or the package has not been built. |
| Tools absent | The client has not reconnected after the server configuration changed. |
| RPC or wallet query fails | The network/RPC setting is missing or does not match the wallet. |
