Choose the server for your task:

| Server | Use it to | Connection |
| :--- | :--- | :--- |
| Swig Docs MCP | Search documentation and find SDK examples | Hosted HTTP endpoint; no API key required |
| Swig Wallet MCP | Configure Solana RPC, inspect wallets, and prepare wallet operations | Run the server locally from `swig-ts` |

## Connect to Swig Docs MCP

Add a remote HTTP MCP server in your assistant's settings with this URL:

```text
https://build.onswig.com/mcp
```

For [Claude Code](https://code.claude.com/docs/en/mcp), run:

```bash
claude mcp add --transport http swig-docs https://build.onswig.com/mcp
```

Open your assistant's MCP tools list and confirm that the Swig documentation
search tools are available. Then try:

```text
Find the Swig Developer SDK guide for creating a wallet and explain the required steps.
```

The docs server supplies documentation context. Wallet operations use the
separate wallet server below.

## Connect to Swig Wallet MCP

Use this server when your agent needs Solana wallet tools. Install
[Bun](https://bun.sh/docs/installation) and Node.js, then build the
[Swig TypeScript repository](https://github.com/anagrambuild/swig-ts):

```bash
git clone https://github.com/anagrambuild/swig-ts.git
cd swig-ts
bun install
bun run build
```

Add the local server to your MCP client. Replace the path with the absolute
path to your checkout:

```json
{
  "mcpServers": {
    "swig-wallet": {
      "command": "node",
      "args": ["/absolute/path/to/swig-ts/packages/mcp-server/dist/index.js"]
    }
  }
}
```

Restart or reconnect the MCP client, then confirm that `configure_rpc` and
`fetch_swig_wallet` appear in its tools list. Configure the intended network
before using wallet tools.

- Follow [Wallet MCP setup](/tutorials/mcp) for RPC configuration, agent keys,
  and your first wallet.
- Use [MCP server reference](/reference/mcp-server) for the tool list and
  authenticated HTTP hosting.
- Give an agent only the [role permissions](/developer-sdk/permissions)
  required for its task, and review transaction actions before signing.

## Documentation files

For tools that consume text directly, use
[llms.txt](https://build.onswig.com/llms.txt) to discover pages or
[llms-full.txt](https://build.onswig.com/llms-full.txt) for the combined docs.
