## Introduction

A direct transfer spends from the wallet vault while the authorized EOA submits the transaction and pays gas.

- **Use when:** you want a simple native-currency payment without a bundler or paymaster.
- **For:** apps using a Secp256k1 role with a native spending allowance.

## How it works

1. Connect the EOA authorized by the selected role.
2. Choose an EOA recipient with no deployed code and an amount within the remaining allowance.
3. Call `signV2` on the config with no calldata and direct-caller authorization.
4. Wait for a successful receipt before treating the payment as complete.

## Transfer fields

| Field | Type | Meaning |
| --- | --- | --- |
| `accountAddress` | Address | Wallet config receiving the execution request |
| `roleId` | Integer | Role that authorizes the spend |
| `recipient` | Address | Receiving EOA |
| `amount` | Integer, wei | Native currency taken from the vault |
| `transactionHash` | Hash | Submitted transaction |

The vault needs the transfer amount. The signer needs gas separately. A 7-wei payment from a 100-wei fixed allowance leaves 93 wei.

## SDK example

Use the delegate from [Add a role](/evm/add-role). The two `"0x"` arguments mean empty call data and direct EOA authorization; the connected sender must be the role's authority.

```typescript
import {
  type Address,
  type LocalAccount,
  createPublicClient,
  createWalletClient,
  http,
} from "viem";
import { getSwigConfig } from "../src/index.js";

export async function sendTransfer(
  rpcUrl: string,
  signer: LocalAccount,
  accountAddress: Address,
  roleId: number,
  recipient: Address,
  amount: bigint,
) {
  const client = createPublicClient({ transport: http(rpcUrl) });
  const wallet = createWalletClient({ account: signer, transport: http(rpcUrl) });
  const config = getSwigConfig(accountAddress, { public: client, wallet });
  const hash = await config.write.signV2(
    [roleId, recipient, amount, "0x", "0x"],
    { chain: null },
  );
  const receipt = await client.waitForTransactionReceipt({ hash });
  if (receipt.status !== "success") throw new Error("Transfer failed");
  return { transactionHash: hash };
}
```

- The outer transaction sends no value; the amount comes from the vault.
- If an included transaction reverts, asset movement and allowance changes revert, while gas is still charged.
- Use [Sponsored transfers](/evm/send-sponsored-transfer) when a paymaster should pay gas.
