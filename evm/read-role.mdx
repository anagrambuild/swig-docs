## Introduction

Reading a role shows who may authorize it and which permissions are attached.

- **Use when:** you need to display access, choose a signer, or inspect a remaining allowance.
- **For:** wallet settings screens and transaction-preparation flows.

## How it works

1. Connect a public RPC client to the wallet config address.
2. Read `getRole` for the on-chain role ID and decode the result.
3. Use its action count to read and decode each permission.
4. Use the resulting fields to explain the role's current access.

## Returned structure

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | Integer | Role ID |
| `authority` | Object | Authority type and signer information |
| `actionCount` | Integer | Number of attached permissions |
| `permissions` | List | Decoded permissions read separately by the example |

A native-limit permission contains `type: "nativeLimit"` and `amount`, its remaining allowance in wei. Recurring permissions contain the allowance, window, last reset, and current amount. EVM recurring windows use timestamp seconds.

## SDK example

This is a read-only operation: no signer or gas is required.

```typescript
import { type Address, createPublicClient, http } from "viem";
import { decodePermission, decodeRole, getSwigConfig } from "../src/index.js";

export async function readRole(rpcUrl: string, accountAddress: Address, roleId: number) {
  const client = createPublicClient({ transport: http(rpcUrl) });
  const config = getSwigConfig(accountAddress, client);
  const role = decodeRole(await config.read.getRole([roleId]));
  const permissions = await Promise.all(
    Array.from({ length: role.actionCount }, async (_, index) =>
      decodePermission(await config.read.getAction([roleId, index])),
    ),
  );
  return { ...role, permissions };
}
```

Illustrative structure for a delegate that has spent 7 of its 100 wei allowance:

```typescript
const exampleRole = {
  id: 1,
  authority: {
    type: "secp256k1",
    address: "0x1111111111111111111111111111111111111111",
  },
  actionCount: 1,

```
