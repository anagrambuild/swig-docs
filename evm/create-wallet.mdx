## Introduction

Wallet creation deploys a config and vault with an initial authority and permissions.

- **Use when:** a user or application needs a new wallet on your selected EVM deployment.
- **For:** onboarding flows using a compatible Swig factory.

## How it works

1. Encode the root authority and give it `All` permission.
2. Choose a public wallet identifier and salt, then predict the config address.
3. Submit factory deployment with any initial vault funding.
4. Confirm the receipt and read the config and vault addresses from `SwigDeployed`.

## Inputs and result

| Field | Type | Meaning |
| --- | --- | --- |
| `factoryAddress` | Address | Compatible Swig factory |
| `walletName` | String | Public value hashed into the wallet ID and salt in this example |
| `initialBalance` | Integer, wei | Native currency deposited into the new vault |
| `accountAddress` | Address | Returned config address for reads and transactions |
| `vaultAddress` | Address | Returned asset-holding address |
| `transactionHash` | Hash | Confirmed creation transaction |

Reusing the same name and root settings targets the same address; deploying it twice reverts. The signer pays initial funding and transaction gas.

## SDK example

Supply a Viem `LocalAccount`, RPC URL, and factory address after [Environment setup](/evm/setup).

```typescript
import {
  type Address,
  type LocalAccount,
  createPublicClient,
  createWalletClient,
  getAddress,
  http,
  keccak256,
  parseEventLogs,
  toBytes,
} from "viem";
import {
  encodeAuthority,
  encodePermission,
  getSwigConfigFactory,
  swigConfigFactoryAbi,
} from "../src/index.js";

export async function createWallet(
  rpcUrl: string,
  signer: LocalAccount,
  factoryAddress: Address,
  walletName: string,
  initialBalance: bigint,
) {
  const client = createPublicClient({ transport: http(rpcUrl) });
  const wallet = createWalletClient({ account: signer, transport: http(rpcUrl) });
  const factory = getSwigConfigFactory(factoryAddress, { public: client, wallet });
  const authority = encodeAuthority({ type: "secp256k1", address: signer.address });
  const id = keccak256(toBytes(walletName));
  const args = [
    id, id, authority.authorityType, authority.key, authority.keyExtra,
    [encodePermission({ type: "all" })],
  ] as const;
  const predicted = await factory.read.computeConfigAddress(args);
  const hash = await factory.write.deploy(args, { chain: null, value: initialBalance });
  const receipt = await client.waitForTransactionReceipt({ hash });
  if (receipt.status !== "success") throw new Error("Wallet creation failed");
  const [event] = parseEventLogs({
    abi: swigConfigFactoryAbi,
    eventName: "SwigDeployed",
    logs: receipt.logs.filter((log) => getAddress(log.address) === getAddress(factoryAddress)),
  });
  if (!event || getAddress(event.args.config) !== getAddress(predicted)) {
    throw new Error("Wallet deployment did not match the predicted address");
  }
  return {
    accountAddress: event.args.config,
    vaultAddress: event.args.vault,
    transactionHash: hash,
  };
}
```

Store the account address for [adding roles](/evm/add-role). Send later asset deposits to the vault address.
