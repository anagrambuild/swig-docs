Use the **source-available TypeScript, Rust, and Python SDKs** with your own keys
and RPC connection. You need a compatible Swig deployment from your operator;
[Environment Setup](/evm/setup) explains how to obtain its details.

## Sponsored transfers

Sponsored operations currently use **already deployed accounts and EntryPoint
v0.9**, with one call per operation. The shared beacon requires a compatible
bundler policy. See [Send a Sponsored Transfer](/evm/send-sponsored-transfer)
for provider requirements and the tested SDK versions.

## Operate a fleet

The shared beacon selects the implementation used by every wallet in the fleet.
It lets an operator upgrade that fleet without individual
user upgrade transactions. [Bundler Compatibility](/evm/bundler-compatibility)
covers account registration and handling operations queued during an upgrade.

Building on Solana? See [Swig on Solana](/solana).
