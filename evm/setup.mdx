## Introduction

Environment setup supplies the RPC connection, deployment addresses, and signer used by the SDK examples.

- **Use when:** you are connecting an application to Swig for the first time or changing networks.
- **For:** developers consuming the source-available EVM SDK.

## How it works

1. Install your language SDK from [Overview](/evm#sdk-example).
2. Obtain the network RPC and a compatible factory address from your deployment operator.
3. Create a read client and, for writes, connect an application-owned signer.
4. Use the config address for wallet operations and the vault address for asset balances.

## Configuration

| Value | Type | Purpose |
| --- | --- | --- |
| RPC URL | URL | Read chain state and submit direct transactions |
| Factory address | Address | Create wallets using the matching deployment |
| Account address | Address | Read and execute through an existing wallet config |
| Signer | Account | Authorize writes; fund its EOA for direct transaction gas |
| Chain | Chain configuration | Select the same network as the RPC and deployment |

Obtain deployment details from your operator or [contact Swig](/links-and-contact). Match the SDK's [contract revision](https://github.com/anagrambuild/swig-protocol-sdk/blob/718f343/evm/abi/source.json); these guides do not assume a public factory address.

## SDK example

The TypeScript examples use Viem and import the source SDK from `../src/index.js`. Save example files under `evm/typescript/examples` in the checkout and run them with `bun run examples/<file>.ts`.

Create clients from an existing signer; keep its key management in your application:

```typescript
import {
  type Chain,
  type LocalAccount,
  createPublicClient,
  createWalletClient,
  http,
} from "viem";

export function connect(rpcUrl: string, chain: Chain, signer: LocalAccount) {
  const transport = http(rpcUrl);
  return {
    client: createPublicClient({ chain, transport }),
    wallet: createWalletClient({ chain, transport, account: signer }),
  };
}
```

- Read-only calls need only the public client.
- Direct writes need gas in the signer's EOA. Funding the vault does not fund that EOA.
- Sponsored writes additionally need a compatible bundler and paymaster; follow [Sponsored transfers](/evm/send-sponsored-transfer).
