This page tracks public security documentation for the Swig protocol.

## Current audit

The `swig-wallet` repository includes a protocol audit from Accretion.

- [2025 Accretion Swig Audit PDF](/audits/2025-accretion-anagram-swig-audit-A25ANA2.pdf)

## Scope

This audit is attached from the protocol repository at:

`swig-wallet/audits/2025-accretion-anagram-swig-audit-A25ANA2.pdf`

The corresponding protocol repository README also states that Swig has been independently audited by Accretion and may undergo additional audits over time.

## How to use this section

- Use the attached PDF when you need the historical review scope and findings
  for the on-chain protocol.
- Treat the audit as one input, not the whole protocol spec. The source of
  truth for current behavior is still the code in `swig-wallet`.
- If additional audits exist for the protocol, developer SDK, IDP SDK, or
  portal backend, they should be listed as separate entries instead of
  replacing the current report.
