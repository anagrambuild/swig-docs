## Start with a task

| Wallet task | Solana | EVM |
| --- | --- | --- |
| Prepare your environment | [TypeScript setup](/tutorials/typescript/env) | [Choose a language](/evm/setup) |
| Create a wallet | [Create a Swig account](/tutorials/typescript/create) | [Deploy a wallet](/evm/create-wallet) |
| Give a key permissions | [Manage authorities](/tutorials/typescript/managing_authorities) | [Add a spending role](/evm/add-role) |
| Send funds | [Transfer SOL](/examples/transfer) | [Transfer native currency](/evm/send-transfer) |
| Sponsor gas or fees | [Hosted Paymaster (API key)](/examples/paymaster) | [ERC-4337 with a compatible bundler](/evm/send-sponsored-transfer) |

Each chain view describes its own prerequisites and supported flows. EVM
sponsorship requires a compatible bundler and paymaster; its Rust and Python
examples use the local test fixture.

## Hosted integrations

Use the API-key-based [Developer SDK](/developer-sdk) when a trusted server
should prepare wallet operations and sponsor submission through Swig's hosted
services.
