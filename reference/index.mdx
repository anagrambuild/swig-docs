# Swig Protocol SDK Overview

The Swig Protocol SDK surface spans both `swig-ts` and `swig-wallet`.

Use this section when you are integrating with the Swig protocol directly rather than going through the hosted developer SDK.

## TypeScript packages in `swig-ts`

The main protocol-facing TypeScript packages are:

- `@swig-wallet/classic` for Web3.js 1.x integrations
- `@swig-wallet/kit` for Solana Kit / Web3.js 2.0 integrations
- `@swig-wallet/lib` for shared core logic
- `@swig-wallet/coder` for lower-level encoding and decoding
- `@swig-wallet/mcp-server` for MCP-based agent access to Swig wallets

## Rust packages in `swig-wallet`

On the Rust side, the protocol-adjacent packages live beside the protocol itself:

- `swig-sdk` for Rust integrations
- `swig-cli` for command-line operations
- protocol-support crates such as `swig-interface`, `swig-state`, and `swig-compact-instructions`

## How to think about this layer

This section is for engineers who want direct protocol access.

Typical use cases:

- wallet-authority management
- transaction signing and execution
- protocol-aware client integrations
- agent tooling via MCP
- backend or CLI tooling against Swig wallets

## What this section does not cover

This section does not cover the hosted, API-key-based Swig Developer SDK. That product family is documented separately under [Swig Developer SDK](/developer-sdk).
