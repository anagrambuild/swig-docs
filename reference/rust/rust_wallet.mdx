title: "Rust Wallet"

The `SwigWallet` is an abstraction for interacting with Swig wallets on chain. It provides a user-friendly interface for managing wallets, authorities, and transactions.

## Overview

The Wallet SDK builds upon the instruction builder to provide comprehensive Swig wallet management. It handles RPC communication, transaction building, and wallet state management.

## Core Components

### SwigWallet Structure

```rust
pub struct SwigWallet<'a> {
    instruction_builder: SwigInstructionBuilder,
    rpc_client: RpcClient,
    fee_payer: &'a Keypair,
    authority: &'a Keypair,
}
```

## Core Functions

### Creating a New Wallet

```rust
pub fn new(
    swig_id: [u8; 32],
    authority_manager: AuthorityManager,
    fee_payer: &'c Keypair,
    authority: &'c Keypair,
    rpc_url: String,
) -> Result<Self, SwigError>
```

Creates a new Swig wallet or initializes an existing one.

## Authority Management


Adds a new authority to the wallet with specified permissions.


Removes an existing authority from the wallet.

## Authorization Locks

Locks reserve part of the wallet's SOL or token balance until an expiry slot.
See [Authorization Locks](/protocol/authorization-locks) for the rules and
[the recipe](/examples/authorization_locks) for a full flow.

### Locking SOL

```rust
pub fn add_sol_authorization_lock(
    &mut self,
    amount: u64,
    expiry_slot: u64,
) -> Result<Signature, SwigError>
```

Reserves `amount` lamports of the wallet address's balance until `expiry_slot`.

### Locking Tokens

```rust
pub fn add_token_authorization_lock(
    &mut self,
    mint: &Pubkey,
    amount: u64,
    expiry_slot: u64,
) -> Result<Signature, SwigError>
```

Reserves `amount` of the wallet's associated token account for `mint`. The token
program (SPL Token or Token-2022) is read from the mint account.

### Locking Any Asset Account

```rust
pub fn add_authorization_lock(
    &mut self,
    asset_account: Pubkey,
    mint: [u8; 32],
    amount: u64,
    expiry_slot: u64,
) -> Result<Signature, SwigError>
```

Lower-level form. Pass the wallet address and an all-zero mint for SOL, or any
token account owned by the wallet address and its mint.

### Releasing or Pruning a Lock

```rust
pub fn remove_authorization_lock(&mut self, lock_id: u32) -> Result<Signature, SwigError>
```

Releases a lock created by the current role, or prunes an expired lock. The
wallet's rent claimer, if any, is resolved automatically.

### Reading Locks

```rust
pub fn get_authorization_locks(&self) -> Result<Vec<AuthorizationLock>, SwigError>
pub fn get_active_authorization_locks(&self) -> Result<Vec<AuthorizationLock>, SwigError>
```

`get_authorization_locks` returns every stored lock, including expired locks
that have not been pruned. `get_active_authorization_locks` returns only locks
still active at the current slot.

## Wallet Information

### Displaying Wallet Details

```rust
pub fn display_swig(&self) -> Result<(), SwigError>
```

Displays detailed information about the wallet, including:

- Account address
- Total roles
- Balance
- Authority details
- Permissions
- Authorization locks, if any

### Getting Wallet Balance

```rust
pub fn get_balance(&self) -> Result<u64, SwigError>
```

Returns the SOL balance of the Swig account.

### Getting Authority Permissions

```rust
pub fn get_current_authority_permissions(&self) -> Result<Vec<Permission>, SwigError>
```

Retrieves the current authority's permissions from the Swig account.

## Examples

### Creating a New Wallet

```rust
let wallet = SwigWallet::new(
    swig_id,
    AuthorityManager::Ed25519(authority_pubkey),
    &fee_payer,
    &authority,
    "https://api.mainnet-beta.solana.com".to_string(),
)?;
```

### Adding an Authority with Permissions

```rust
let signature = wallet.add_authority(
    AuthorityType::Ed25519,
    &new_authority_bytes,
    vec![
        Permission::All,
        Permission::Sol {
            amount: 1_000_000_000, // 1 SOL
            recurring: None,
        },
    ],
)?;
```

### Granting and Using an Authorization Lock Role

```rust
wallet.add_authority(
    AuthorityType::Ed25519,
    &card_authority_bytes,
    vec![
        Permission::ManageAuthorizationLocks {
            max_duration_slots: 216_000,
        },
        Permission::Sol {
            amount: 2_000_000_000, // backs the role's holds
            recurring: None,
        },
    ],
)?;

// As the card role:
let slot = wallet.get_current_slot()?;
wallet.add_sol_authorization_lock(1_500_000_000, slot + 400)?;
```

### Creating a Session

```rust
wallet.create_session(
    session_keypair.pubkey(),
    1000, // Duration in slots
)?;
```

### Signing a Transaction

```rust
let signature = wallet.sign(
    vec![transfer_instruction],
    None, // No address lookup tables
)?;
```
