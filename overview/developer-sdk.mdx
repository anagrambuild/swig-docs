Use the Developer SDK section when your backend keeps the API key and prepares
wallet actions for the client to sign. The hosted server SDK is available for
TypeScript and Python, both at version `0.8.0`, from
[anagrambuild/swig-developer-sdk](https://github.com/anagrambuild/swig-developer-sdk).

Start there for:

- wallet creation
- transfers, swaps, and grouped operations
- balance, token activity, and role reads
- fiat on-ramp and off-ramp
- sponsor and paymaster-backed submission
