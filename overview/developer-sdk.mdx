Use the Developer SDK section when a trusted server keeps the API key,
prepares wallet actions, and submits application-signed transactions. The SDK
does not expose the API client or API key in browser or mobile code. These docs
cover TypeScript, Python, and the native Rust preview from the standalone repository.
All three live in
[anagrambuild/swig-developer-sdk](https://github.com/anagrambuild/swig-developer-sdk).

Start there for:

- wallet creation
- transfers, swaps, and grouped operations
- balance, token activity, and role reads
- fiat ramp orders, buying and selling
- sponsor and paymaster-backed submission
