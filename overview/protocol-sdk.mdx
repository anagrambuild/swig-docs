Use the Protocol SDK when your application controls wallet authorities, signing,
and protocol access directly. Your code builds transactions and submits them
through your chosen chain client.

Solana packages cover TypeScript and Rust. EVM SDKs are available from source
for TypeScript, Rust, and Python. The chain guides explain their own setup and
supported flows.

<Card title="Choose your chain" icon="terminal" href="/reference">
  Open the Solana or EVM guides to create wallets, assign permissions, and send funds.
</Card>

For API-key-based transaction preparation through Swig's hosted services, use
the [Developer SDK](/developer-sdk).
