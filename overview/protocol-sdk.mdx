Use the Protocol SDK section when your app integrates with Swig wallets
directly. EVM examples cover TypeScript, Rust, and Python; Solana packages cover
TypeScript and Rust.

Start there for:

- TypeScript packages such as `classic` and `kit`
- Rust packages and instruction builders
- direct signing and execution patterns
- MCP tooling and protocol examples
- EVM wallet creation, roles, direct transfers, and sponsored transfers
