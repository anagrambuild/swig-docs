## Introduction

This dataset contains native stake positions and aggregate balances for a Swig
wallet. Use it to show earning SOL, follow activation, and track cooldown.
Indexed state can lag the chain; `lastUpdatedAt` identifies the latest observation.

Use the configured TypeScript `swig.yield` or Python `swig.yields` client. Rust has no yield client. Each admitted call/page consumes one API request; see [Pricing & quotas](/query#api-requests).

## SDK examples

### List positions

Query indexed stake accounts to show earning balances or track cooldown.

<CodeGroup>
```typescript TypeScript
const yieldClient = swig.yield.forWallet({
  swigConfigAddress,
  network: 'mainnet',
});
const result = await yieldClient.listPositions({ pageSize: 50 });
```

```python Python
result = await swig.yields.list_positions(
    swig_config_address=swig_config_address,
    network="mainnet",
    page_size=50,
)
```
</CodeGroup>

### Get the yield summary

Fetch aggregate position, withdrawable, and recorded reward amounts.

<CodeGroup>

```typescript TypeScript
const summary = await yieldClient.getSummary();
```

```python Python
summary = await swig.yields.get_summary(swig_config_address=swig_config_address)
```

</CodeGroup>

#### SDK returned structure

Illustrative output; Python shows the dataclass as JSON.

<CodeGroup>


```json Python
{ "total_position_lamports": "5000000000", "withdrawable_lamports": "0", "recorded_rewards_lamports": "10000000" }
```

</CodeGroup>

### Page through positions

Keep the wallet and network unchanged, and stop when the next token is absent.

<CodeGroup>

```typescript TypeScript
if (result.nextPageToken) {
  const nextPage = await yieldClient.listPositions({
    pageSize: 50, pageToken: result.nextPageToken,
  });
}
```

```python Python
if result.next_page_token:
    next_page = await swig.yields.list_positions(
        swig_config_address=swig_config_address,
        page_size=50, page_token=result.next_page_token,
    )
```

</CodeGroup>

## Input parameters

| Parameter | Requirement |
| :--- | :--- |
| `swigConfigAddress` / `swig_config_address` | Wallet config owned by the API key’s organization. |
| `network` | Wallet network; otherwise use the client setting. |
| `pageSize` / `page_size` | 50 by default, maximum 200 for position/reward pages. |
| `pageToken` / `page_token` | Previous continuation token for the same organization, wallet, network, and collection. |

## Returned result

TypeScript field names are shown below; Python uses snake_case attributes.
Lamport amounts are exact decimal strings in both SDKs.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `positions` | array | Indexed positions, sorted by address |
| `positions[].swigConfigAddress` | string | Wallet configuration account |
| `positions[].walletAddress` | string | Wallet that controls the position |
| `positions[].positionAddress` | string | Stake position account |
| `positions[].validatorVoteAddress` | string, optional | Validator vote account, when known |
| `positions[].state` | string | `activating`, `active`, `deactivating`, `inactive`, or `unspecified` |
| `positions[].balanceLamports` | string | Full position balance, including rent |
| `positions[].rentLamports` | string | Rent reserve |
| `positions[].positionLamports` | string | Balance excluding rent; compounded rewards are already included |
| `positions[].earningLamports` | string | Stake currently earning rewards |
| `positions[].withdrawableLamports` | string | Indexed withdrawable amount; can include rent |
| `nextPageToken` | string, optional | Continuation token; absent on the final page |
| `lastUpdatedAt` | string, optional | Latest indexed update; absent before the first observation |

The withdrawal preparation flow keeps the rent reserve. Use its
`withdrawalLamports` to show the amount a prepared withdrawal will return.

| Summary field | Meaning |
| :--- | :--- |
| `totalPositionLamports` | Total position balance excluding rent; already includes compounded rewards. |
| `withdrawableLamports` | Indexed withdrawable balance; may include rent. |
| `recordedRewardsLamports` | Recorded credits; do not add them again to position balances. |

## Errors

| Error | Meaning |
| :--- | :--- |
| Wallet access denied | The API key's organization does not own the Swig config. Use the owning organization's key and correct network. |
| Invalid continuation token | The token is malformed or does not match its organization, network, and wallet. Restart pagination or use the original query scope. |
| API quota exhausted | The applicable request allowance has reached its admission cap. Check Pricing & quotas before retrying. |
