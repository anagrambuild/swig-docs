## Introduction

This dataset contains native SOL staking positions indexed for a Swig wallet:
their validator, lifecycle state, principal, rent, and withdrawable balance.
Use it for staking dashboards, tracking cooldown, and displaying earning or
withdrawable SOL.

The example lists positions. TypeScript exposes `swig.yield`; Python exposes
`swig.yields`. The same clients also provide
[validator rates, reward estimates, totals, and reward history](/developer-sdk/yield#read-positions-rewards-and-estimates).
For deposits, exits, and withdrawals, use the [Finance yield guide](/developer-sdk/yield).

Position data can lag the chain. `lastUpdatedAt` identifies its latest recorded
update. Each admitted call or page consumes **one API request**, including
retries and admitted errors. See [pricing and quotas](/query#api-requests).

## Returned result

TypeScript field names are shown below; Python uses snake_case attributes.
Lamport amounts are exact decimal strings in both SDKs.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `positions` | array | Indexed positions, sorted by address |
| `positions[].swigConfigAddress` | string | Wallet configuration account |
| `positions[].walletAddress` | string | Wallet that controls the position |
| `positions[].positionAddress` | string | Stake position account |
| `positions[].validatorVoteAddress` | string, optional | Validator vote account, when known |
| `positions[].state` | string | `activating`, `active`, `deactivating`, `inactive`, or `unspecified` |
| `positions[].balanceLamports` | string | Full position balance, including rent |
| `positions[].rentLamports` | string | Rent reserve |
| `positions[].positionLamports` | string | Balance excluding rent; compounded rewards are already included |
| `positions[].earningLamports` | string | Stake currently earning rewards |
| `positions[].withdrawableLamports` | string | Indexed withdrawable amount; can include rent |
| `nextPageToken` | string, optional | Continuation token; absent on the final page |
| `lastUpdatedAt` | string, optional | Latest indexed update; absent before the first observation |

The withdrawal preparation flow keeps the rent reserve. Use its
`withdrawalLamports` to show the amount a prepared withdrawal will return.

## Input parameters

Start with [Client setup](/developer-sdk/integration-paths) and use your wallet's
network. The API key's organization must own the Swig config.

| TypeScript / Python | Required | Description |
| :--- | :--- | :--- |
| `swigConfigAddress` / `swig_config_address` | Yes | Wallet config address; TypeScript binds it with `forWallet` |
| `network` | No | `mainnet` or `devnet`; defaults to the client's setting |
| `pageSize` / `page_size` | No | 50 by default; maximum 200 |
| `pageToken` / `page_token` | No | Previous `nextPageToken` / `next_page_token` |

Continuation tokens remain scoped to the original organization, network, and
wallet. Stop paging when the response has no next token.

## SDK example

<CodeGroup>
```typescript TypeScript
const yieldClient = swig.yield.forWallet({
  swigConfigAddress,
  network: 'mainnet',
});
const result = await yieldClient.listPositions({ pageSize: 50 });
```

```python Python
result = await swig.yields.list_positions(
    swig_config_address=swig_config_address,
    network="mainnet",
    page_size=50,
)
```
</CodeGroup>
