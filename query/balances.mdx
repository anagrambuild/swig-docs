## Introduction

This dataset contains the native SOL and token balances recorded for a Swig
wallet, along with token metadata, prices, and total USD value. Use it to build
portfolio views, show available holdings, or display a wallet's value.

The example uses `listTokenBalances` / `list_token_balances`. For only the USD
total, use `getUsdBalance` / `get_usd_balance`; see the
[balance methods](/developer-sdk/wallet-reads#balances).

These queries use recorded data and can lag chain state. Track transaction
confirmation separately. Each admitted call consumes **one API request**;
retries and admitted errors also count. See [pricing and quotas](/query#api-requests).

## Returned result

TypeScript field names are shown below. Python uses snake_case names.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `swigConfigAddress` | string | Swig configuration account queried |
| `walletAddress` | string | Wallet address that holds the assets |
| `balances` | array | Native SOL and token balance records |
| `balances[].assetKind` | string, optional | `native-sol`, `token`, or `unspecified` |
| `balances[].mintAddress` | string | Asset mint identifier |
| `balances[].tokenProgram` | number | Token-program discriminator |
| `balances[].tokenSymbol`, `tokenName` | string | Display symbol and name |
| `balances[].decimals` | number | Decimal places used by the asset |
| `balances[].amountRaw` | string | Exact amount in base units; use for arithmetic |
| `balances[].uiAmount` | number | Amount scaled by decimals for display |
| `balances[].usdPrice` | number | USD price per whole token |
| `balances[].usdValue` | number | USD value of this holding |
| `totalUsdValue` | number | Total USD value across the wallet's holdings |

Rust returns `WalletBalanceSummary`: native SOL is in `sol_balance`, and
`token_balances` is a map keyed by mint. Its exact amounts are `u64` values.
The returned structures below show the language differences.

## Input parameters

Start with [Client setup](/developer-sdk/integration-paths). Keep the API key on
your server. These queries require no wallet-authority signature.

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `swigConfigAddress` / `swig_config_address` | Yes | Swig **config address**; a string in TypeScript/Python and a `Pubkey` in Rust |
| `network` | Client setting | Configure the client for `mainnet` or `devnet`; Rust uses `Network::Mainnet` or `Network::Devnet` |

## SDK example

Use `swig` from client setup in TypeScript/Python, or the `wallet` client in Rust.
Supply the configuration address of the wallet you want to query.

<CodeGroup>
```typescript TypeScript
const wallet = swig.wallets.use(swigConfigAddress);
const result = await wallet.listTokenBalances();
```

```python Python
wallet = swig.wallets.use(swig_config_address)
result = await wallet.list_token_balances()
```

```rust Rust
let result = wallet.list_token_balances(&swig_config_address).await?;
```
</CodeGroup>

`ListSwigTokenBalancesResult` dataclass; its JSON view is shown below. Rust
returns the typed structure shown in its tab. USD and UI values are for display;
use exact integer amounts for arithmetic.

```rust Rust
use solana_pubkey::Pubkey;
use std::collections::BTreeMap;

pub struct SolBalance {
    pub lamports: u64,
    pub ui_amount: f64,
    pub usd_price: f64,
    pub usd_value: f64,
}

pub struct TokenBalance {
    pub mint_address: Pubkey,
    pub token_program: Pubkey,
    pub symbol: String,
    pub name: String,
    pub decimals: u32,
    pub amount_raw: u64,
    pub ui_amount: f64,
    pub usd_price: f64,
    pub usd_value: f64,
}

pub struct WalletBalanceSummary {
    pub swig_config_address: Pubkey,
    pub wallet_address: Pubkey,
    pub sol_balance: Option<SolBalance>,
    pub token_balances: BTreeMap<Pubkey, TokenBalance>,
    pub total_usd_value: f64,
}
```
