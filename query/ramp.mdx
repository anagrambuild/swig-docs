## Introduction

Ramp data describes supported checkout options, current quotes, and stored order
status. Use it to build buy/sell forms, compare available routes, and track
customer settlement. TypeScript, Python, and Rust support these queries.

Each admitted options, quote, or order call consumes **one API request**, including
retries and admitted errors. See [Pricing & quotas](/query#api-requests).

## SDK examples

### List Ramp options

Query supported choices for the provider configuration and customer’s country.

<CodeGroup>
```typescript TypeScript
const result = await swig.ramp.getOptions({
  configurationId,
  environment: 'sandbox',
  direction: 'buy',
  countryCode: 'US',
});
```

```python Python
result = await swig.ramp.get_options(
    configuration_id=configuration_id,
    environment="sandbox",
    direction="buy",
    country_code="US",
)
```

```rust Rust
use swig_developer_sdk::{
    GetRampOptionsArgs, RampClient, RampConfig, RampDirection, RampEnvironment,
};

let ramp = RampClient::new(config, Some(RampConfig {
    configuration_id,
    environment: RampEnvironment::Sandbox,
}))?;
let result = ramp.get_options(GetRampOptionsArgs {
    direction: RampDirection::Buy,
    country_code: Some("US".into()),
    fiat_currency_code: None,
}).await?;
```
</CodeGroup>

### Get quotes

Get current route prices for the chosen amount, asset, and location. An empty list means no offer is available.

<CodeGroup>

```typescript TypeScript
const quotes = await swig.ramp.getQuotes({
  configurationId,
  environment: 'sandbox',
  location: { countryCode: 'US' },
  order: {
    type: 'buy',
    spend: { currencyCode: 'USD', minorUnits: 10_000n },
    receive: { type: 'token', mint: usdcMint },
  },
});
```

```python Python
from swig_developer_sdk import FiatAmountInput, RampBuyOrderRequest, RampLocation, SplTokenAsset

quotes = await swig.ramp.get_quotes(
    configuration_id=configuration_id,
    environment="sandbox",
    location=RampLocation(country_code="US"),
    order=RampBuyOrderRequest(
        spend=FiatAmountInput(currency_code="USD", minor_units=10_000),
        receive=SplTokenAsset(mint=usdc_mint),
    ),
)
```

```rust Rust
use swig_developer_sdk::{
    CryptoAsset, FiatAmount, GetRampQuotesArgs, RampLocation, RampOrderRequest,
};

let quotes = ramp
    .get_quotes(GetRampQuotesArgs {
        location: RampLocation {
            country_code: "US".into(),
            subdivision_code: None,
        },
        order: RampOrderRequest::Buy {
            spend: FiatAmount {
                currency_code: "USD".into(),
                minor_units: 10_000,
            },
            receive: CryptoAsset::Token { mint: usdc_mint },
        },
    })
    .await?;
```

## Input parameters

| TypeScript / Python | Required | Description |
| :--- | :--- | :--- |
| `configurationId` / `configuration_id` | Yes | Your Ramp configuration ID; set on `RampClient` in Rust |
| `environment` | Yes | `sandbox` or `production`; set on `RampClient` in Rust |
| `direction` | Yes | `buy` or `sell` |
| `countryCode` / `country_code` | No | Filter by country; omitting it returns countries alone |
| `fiatCurrencyCode` / `fiat_currency_code` | No | Further narrow the available options |

Provider environment is separate from Solana network. Sandbox orders still settle
on mainnet. Use the server client from [Client setup](/developer-sdk/integration-paths).

| Operation | Input | Meaning |
| :--- | :--- | :--- |
| Quote | `location`, `order` | Country/subdivision plus buy or sell amount and asset. Fiat uses minor units, crypto uses base units. |
| Order status | `orderId` / `order_id` | Stored order identifier; no quote or provider configuration is needed. |

## Returned result

TypeScript field names are shown below; Python and Rust use snake_case.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `countries` | array | Supported countries |
| `countries[].code`, `name` | string | Country code and display name |
| `countries[].subdivisions` | array | Subdivision codes and names |
| `fiatCurrencies` | array | Supported fiat currencies |
| `fiatCurrencies[].currencyCode` | string | Currency code, such as `USD` |
| `fiatCurrencies[].exponent` | number | Minor-unit decimal places; USD uses 2 |
| `paymentMethods` | string array | Available payment-method identifiers |
| `assets` | array | Supported crypto assets |
| `assets[].asset` | object | Native SOL (`type: sol`) or a token (`type: token`, with `mint`) |
| `assets[].name` | string | Asset display name |
| `assets[].iconUrl` | string, optional | Asset image URL |
| `assets[].decimals` | number | Base-unit decimal places |

Rust represents the asset as `CryptoAsset::Sol` or `CryptoAsset::Token { mint }`,
where the mint is a `Pubkey`. Country and currency collections are typed vectors.

| Operation | Field | Meaning |
| :--- | :--- | :--- |
| Quote | `route.provider`, `route.paymentMethod` | Customer-selectable provider and payment method. |
| Quote | `details` | Buy: fiat spend and crypto receive. Sell: crypto sell and fiat receive. Both include total fee and exact decimal-string exchange rate. |
| Order | `id`, `type`, `status`, `createdAt`, `updatedAt`, `quote` | Current stored order and its price. Querying non-final status may refresh provider state. |
| Order | Optional `launchUrl` | Private customer checkout URL; keep it out of logs. |
| Sell order | Optional `deposit`, `transfer` | Provider deposit and attempt state, IDs, expiry, and optional Solana signature. Fetching an order does not submit or resolve a transfer. |

Quotes have no ID and must not be cached; order creation obtains a fresh price.
A settled order may later become refunded. For buy/sell creation and transfer
recovery, use [Finance Ramp](/developer-sdk/ramp).

## Errors

| Error | Meaning |
| :--- | :--- |
| Missing or invalid configuration | The Ramp configuration or provider environment is unavailable to the caller. Use the configuration ID and sandbox/production environment belonging to your organization. |
| Invalid options input | A supplied country or currency value is empty or invalid. Omit optional filters or supply supported nonempty values. |
| Provider unavailable or request timed out | The options request could not complete. Retry the query according to your client policy; each admitted retry counts. |
| Order not found | The stored order ID is unavailable to this organization. |
