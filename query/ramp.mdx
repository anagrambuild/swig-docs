## Introduction

Ramp options describe the countries, fiat currencies, payment methods, and crypto
assets available for your configuration. Use this dataset to build a buy/sell
form that shows supported choices before requesting a quote.

The example queries options. The same SDK also supports [quotes and order status](/developer-sdk/ramp).
Quotes are temporary and have no reusable quote ID; creating an order obtains a
fresh price. Reading a non-final order may refresh its provider state, but does
not submit a transfer. Keep customer-specific launch URLs out of logs.

Each admitted options, quote, or order query consumes **one API request**,
including retries and admitted errors. See [Pricing & quotas](/query#api-requests).

## Returned result

TypeScript field names are shown below; Python and Rust use snake_case.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `countries` | array | Supported countries |
| `countries[].code`, `name` | string | Country code and display name |
| `countries[].subdivisions` | array | Subdivision codes and names |
| `fiatCurrencies` | array | Supported fiat currencies |
| `fiatCurrencies[].currencyCode` | string | Currency code, such as `USD` |
| `fiatCurrencies[].exponent` | number | Minor-unit decimal places; USD uses 2 |
| `paymentMethods` | string array | Available payment-method identifiers |
| `assets` | array | Supported crypto assets |
| `assets[].asset` | object | Native SOL (`type: sol`) or a token (`type: token`, with `mint`) |
| `assets[].name` | string | Asset display name |
| `assets[].iconUrl` | string, optional | Asset image URL |
| `assets[].decimals` | number | Base-unit decimal places |

Rust represents the asset as `CryptoAsset::Sol` or `CryptoAsset::Token { mint }`,
where the mint is a `Pubkey`. Country and currency collections are typed vectors.

## Input parameters

| TypeScript / Python | Required | Description |
| :--- | :--- | :--- |
| `configurationId` / `configuration_id` | Yes | Your Ramp configuration ID; set on `RampClient` in Rust |
| `environment` | Yes | `sandbox` or `production`; set on `RampClient` in Rust |
| `direction` | Yes | `buy` or `sell` |
| `countryCode` / `country_code` | No | Filter by country; omitting it returns countries alone |
| `fiatCurrencyCode` / `fiat_currency_code` | No | Further narrow the available options |

Provider environment is separate from Solana network. Sandbox orders still settle
on mainnet. Use the server client from [Client setup](/developer-sdk/integration-paths).

## Errors

| Failure | Cause | What to do |
| :--- | :--- | :--- |
| Missing or invalid configuration | The Ramp configuration or provider environment is unavailable to the caller. | Use the configuration ID and sandbox/production environment belonging to your organization. |
| Invalid options input | A supplied country or currency value is empty or invalid. | Omit optional filters or supply supported nonempty values. |
| Provider unavailable or request timed out | The options request could not complete. | Retry the read according to your client policy; each admitted retry counts. |

## SDK example

<CodeGroup>
```typescript TypeScript
const result = await swig.ramp.getOptions({
  configurationId,
  environment: 'sandbox',
  direction: 'buy',
  countryCode: 'US',
});
```

```python Python
result = await swig.ramp.get_options(
    configuration_id=configuration_id,
    environment="sandbox",
    direction="buy",
    country_code="US",
)
```

```rust Rust
use swig_developer_sdk::{
    GetRampOptionsArgs, RampClient, RampConfig, RampDirection, RampEnvironment,
};

let ramp = RampClient::new(config, Some(RampConfig {
    configuration_id,
    environment: RampEnvironment::Sandbox,
}))?;
let result = ramp.get_options(GetRampOptionsArgs {
    direction: RampDirection::Buy,
    country_code: Some("US".into()),
    fiat_currency_code: None,
}).await?;
```
</CodeGroup>

## SDK returned structure

Illustrative TypeScript output, not a live availability quote. Python returns
`RampOptions` with snake_case fields; Rust returns the typed structure below.

<CodeGroup>
```json TypeScript
{
  "countries": [
    { "code": "US", "name": "United States", "subdivisions": [
      { "code": "CA", "name": "California" }
    ] }
  ],
  "fiatCurrencies": [{ "currencyCode": "USD", "exponent": 2 }],
  "paymentMethods": ["CREDIT_DEBIT_CARD"],
  "assets": [{ "asset": { "type": "sol" }, "name": "Solana", "decimals": 9 }]
}
```

```json Python
{
  "countries": [
    { "code": "US", "name": "United States", "subdivisions": [
      { "code": "CA", "name": "California" }
    ] }
  ],
  "fiat_currencies": [{ "currency_code": "USD", "exponent": 2 }],
  "payment_methods": ["CREDIT_DEBIT_CARD"],
  "assets": [{ "asset": { "type": "sol" }, "name": "Solana", "icon_url": null, "decimals": 9 }]
}
```

```rust Rust
pub struct RampOptions {
    pub countries: Vec<RampCountry>,
    pub fiat_currencies: Vec<RampFiatCurrencyOption>,
    pub payment_methods: Vec<String>,
    pub assets: Vec<RampAssetOption>,
}
```
</CodeGroup>

The Python block is a JSON view of the returned dataclasses. For transport
fields, see the [Ramp API reference](/developer-api/ramp).
