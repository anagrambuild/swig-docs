## Introduction

Stake SOL from a Swig wallet with an allowlisted validator. Use this flow to
choose a validator, authorize a staking role, and deposit principal. TypeScript
and Python support yield; Rust has no yield client.

Use [configured clients](/developer-sdk/integration-paths) on the wallet’s network.
Writes prepare unsigned transactions. [Sign](/developer-sdk/signers), submit,
and confirm each transaction before its dependent step.

## SDK examples

### List yield options

Choose an allowlisted validator that accepts new deposits. These examples use `swig` configured for the wallet’s network; TypeScript binds it once as `yieldClient`. Address variables are public keys.

<CodeGroup>

```typescript TypeScript
const yieldClient = swig.yield.forWallet({
  swigConfigAddress: swigConfigAddress,
  network: 'mainnet',
});

const options = await yieldClient.listOptions();
const validator = options.find((option) => option.acceptsDeposits);
if (!validator) throw new Error('No validator currently accepts deposits');
// validator.rate?.estimatedNetAprBps: 600 = 6% APR after commission
```

```python Python
options = await swig.yields.list_options(
    network="mainnet", swig_config_address=swig_config_address,
)
validator = next((option for option in options if option.accepts_deposits), None)
if validator is None:
    raise ValueError("No validator currently accepts deposits")
# If validator.rate is not None:
# validator.rate.estimated_net_apr_bps: 600 = 6% APR after commission
```

</CodeGroup>

### Prepare a role that can stake

Reuse a qualifying role or prepare a narrowly scoped role for your yield authority.

<CodeGroup>

```typescript TypeScript
const role = await yieldClient.prepareRole({
  feePayer: feePayer,
  yieldAuthority: { ed25519: { publicKey: agentKey } },
  validatorVoteAddress: validator.voteAddress,
  maxDeposit: 10_000_000_000n,
  // Only needed to create a role.
  roleManagerAuthority: { ed25519: { publicKey: adminKey } },
});

if (role.type === 'create') {
  // Sign role.transaction with the role manager and fee payer, submit it, and
  // wait for confirmation. Then call prepareRole again without roleId.
}
```

```python Python
from swig_developer_sdk import PreparedYieldRoleCreation

role = await swig.yields.prepare_role(
    network="mainnet",
    swig_config_address=swig_config_address,
    fee_payer=fee_payer,
    yield_authority={"ed25519": {"public_key": agent_key}},
    validator_vote_address=validator.vote_address,
    max_deposit=10_000_000_000,
    role_manager_authority={"ed25519": {"public_key": admin_key}},
)
if isinstance(role, PreparedYieldRoleCreation):
    ...  # sign, submit and confirm role.transaction, then call prepare_role again
```

</CodeGroup>

A `create` result contains an unsigned AddRole transaction. Complete [signing](/developer-sdk/signers), submit, and confirm it before continuing. An `existing` result is ready to use.

### Deposit SOL

Prepare a new position funded by the wallet. The fee payer supplies rent and fees.

<CodeGroup>

```typescript TypeScript
const deposit = await yieldClient.deposit({
  feePayer: feePayer,
  requesterAuthority: { ed25519: { publicKey: agentKey } },
  amount: 5_000_000_000n, // principal, excluding rent and fees
  validatorVoteAddress: validator.voteAddress,
  positionSeed: positionSeed,
});
// deposit.positionAddress, deposit.rentLamports (funded by the fee payer)
```

```python Python
deposit = await swig.yields.deposit(
    network="mainnet",
    swig_config_address=swig_config_address,
    fee_payer=fee_payer,
    requester_authority={"ed25519": {"public_key": agent_key}},
    amount=5_000_000_000,
    validator_vote_address=validator.vote_address,
    position_seed=position_seed,
)
```

</CodeGroup>

Sign and submit `deposit.transaction`, then wait for confirmation. Keep the returned position address to track activation.

## Flow

```text
Choose validator
  └─ Authorize role
      └─ Deposit
          └─ Confirm
```

## Input

| Operation | Input | Requirement |
| :--- | :--- | :--- |
| All | Wallet config and network | Use [Client setup](/developer-sdk/integration-paths). TypeScript uses `swig.yield`; Python uses `swig.yields`. Rust has no yield client. |
| Write | `feePayer`, `requesterAuthority`, optional `roleId` | Public fee payer and authorized wallet authority. Python uses snake_case names. Omit role ID to select the lowest capable role. |
| Role | `yieldAuthority`, `maxDeposit`, `validatorVoteAddress` | Authority to grant access, positive lamport budget, and a validator accepting deposits. Optional `roleId` checks a specific candidate. |
| Role creation | `roleManagerAuthority` | Ed25519 or secp256r1 authority with `All` or `ManageAuthority`; needed only when no reusable role exists. |
| Deposit | `amount`, `positionSeed`, `validatorVoteAddress` | Positive principal in lamports, at least the network minimum. ASCII seed of 1–32 bytes; persist it for this attempt. Wallet retains its rent reserve. |

`prepareRole` reuses `All` or `AllButManageAuthority`, or a role with System and
Stake program access, a general SOL allowance covering `maxDeposit`, and
`StakeAll`. A finite stake limit can authorize an individual operation but does
not qualify for automatic reuse because withdrawals may include rewards.
New roles receive exactly `Program(System)`, `Program(Stake)`,
`SolLimit(maxDeposit)`, and `StakeAll`. `StakeAll` alone cannot invoke the Stake
program; `ProgramCurated` does not cover it. Existing roles remain unchanged.

## Output

| Operation | Field | Meaning |
| :--- | :--- | :--- |
| Options | `voteAddress`, `name`, `acceptsDeposits`, optional `rate` | Allowlisted validators, including those closed to new deposits. Existing positions can exit while the validator remains allowlisted. |
| Rate | `estimatedNetAprBps`, `commissionBps`, `lastUpdatedAt` | 600 APR basis points means 6% after commission. Observation time and rate may be absent; rates can change. |
| Role | `type`, `roleId` or `transaction`, `actions` | `existing` identifies a qualifying role; `create` returns the AddRole transaction and exact new grants. |
| Deposit | `transaction`, `positionAddress`, `delegatedLamports`, `rentLamports` | Unsigned deposit and the fee payer’s rent contribution. |

### Track the deposit

Use [Yield position](/query/yield) to follow activation and earning balances,
[Yield reward](/query/yield-rewards) for credited rewards, and
[Yield withdrawal](/developer-sdk/yield-withdrawal) to exit and return funds.

## Errors

| Error | Meaning |
| :--- | :--- |
| `INVALID_ARGUMENT` | Malformed input, unsupported validator, or invalid amount/seed. |
| `NOT_FOUND` | The wallet is not owned by the API key’s organization. |
| `PERMISSION_DENIED` | The selected role lacks program access, stake permission, or remaining SOL allowance; role creation needs a managing authority. |
| `FAILED_PRECONDITION` | Insufficient funds, stake lockup, or an incompatible position state, including withdrawal before cooldown completes. |
| `ALREADY_EXISTS` | The deposit or split seed identifies an existing account. Reconcile the earlier submission before choosing another seed. |
| `UNAVAILABLE` | RPC, rate, or index data is temporarily unavailable. |
