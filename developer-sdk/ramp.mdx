## Introduction

Buy crypto with fiat and deliver it to a Swig wallet. This flow covers route
selection and order creation; the customer completes the provider checkout.
[Query Ramp options](/query/ramp) first to populate supported country, currency,
asset, and payment-method choices.

Use [Client setup](/developer-sdk/integration-paths) and the provider configuration. Sandbox is a provider environment, not a Solana devnet setting; sell transfers use mainnet even in sandbox.

## SDK examples

### Required configuration

TypeScript and Python use the configured `swig` client. Rust binds the provider configuration to a separate client.

<CodeGroup>

```rust Rust
use swig_developer_sdk::{RampClient, RampConfig, RampEnvironment};

let ramp = RampClient::new(config, Some(RampConfig {
    configuration_id,
    environment: RampEnvironment::Sandbox,
}))?;
```

</CodeGroup>

### Quote a buy

Get current buy offers for the selected asset, amount, and location.

<CodeGroup>

```typescript TypeScript
const quotes = await swig.ramp.getQuotes({
  configurationId,
  environment: 'sandbox',
  location: { countryCode: 'US' },
  order: {
    type: 'buy',
    spend: { currencyCode: 'USD', minorUnits: 10_000n },
    receive: { type: 'token', mint: usdcMint },
  },
});
```

```python Python
from swig_developer_sdk import FiatAmountInput, RampBuyOrderRequest, RampLocation, SplTokenAsset

quotes = await swig.ramp.get_quotes(
    configuration_id=configuration_id,
    environment="sandbox",
    location=RampLocation(country_code="US"),
    order=RampBuyOrderRequest(
        spend=FiatAmountInput(currency_code="USD", minor_units=10_000),
        receive=SplTokenAsset(mint=usdc_mint),
    ),
)
```

```rust Rust
use swig_developer_sdk::{
    CryptoAsset, FiatAmount, GetRampQuotesArgs, RampLocation, RampOrderRequest,
};

let quotes = ramp
    .get_quotes(GetRampQuotesArgs {
        location: RampLocation {
            country_code: "US".into(),
            subdivision_code: None,
        },
        order: RampOrderRequest::Buy {
            spend: FiatAmount {
                currency_code: "USD".into(),
                minor_units: 10_000,
            },
            receive: CryptoAsset::Token { mint: usdc_mint },
        },
    })
    .await?;
```

</CodeGroup>

An empty list means no offer is available. Present the returned `route` and `details` for selection; the next example uses the customer-approved `selectedRoute` / `selected_route`. Quotes have no ID and are re-priced at order creation.

### Create a buy order

Create checkout using the selected quote route and the same amount, asset, and location. Supply a previously saved request ID.

<CodeGroup>

```typescript TypeScript
const order = await swig.ramp.createOrder({
  requestId,
  configurationId,
  environment: 'sandbox',
  context: {
    customerId,
    swigConfigAddress,
    location: { countryCode: 'US' },
  },
  route: selectedRoute,
  order: {
    type: 'buy',
    spend: { currencyCode: 'USD', minorUnits: 10_000n },
    receive: { type: 'token', mint: usdcMint },
  },
});
```

```python Python
from swig_developer_sdk import RampOrderContext

order = await swig.ramp.create_order(
    request_id=request_id,
    configuration_id=configuration_id,
    environment="sandbox",
    context=RampOrderContext(
        customer_id=customer_id,
        swig_config_address=swig_config_address,
        location=RampLocation(country_code="US"),
    ),
    route=selected_route,
    order=RampBuyOrderRequest(
        spend=FiatAmountInput(currency_code="USD", minor_units=10_000),
        receive=SplTokenAsset(mint=usdc_mint),
    ),
)
```

```rust Rust
use swig_developer_sdk::{
    CreateRampOrderArgs, CryptoAsset, FiatAmount, RampLocation, RampOrderContext,
    RampOrderRequest,
};

let order = ramp
    .create_order(CreateRampOrderArgs {
        request_id,
        context: RampOrderContext {
            customer_id,
            swig_config_address,
            location: RampLocation {
                country_code: "US".into(),
                subdivision_code: None,
            },
        },
        route: selected_route,
        order: RampOrderRequest::Buy {
            spend: FiatAmount {
                currency_code: "USD".into(),
                minor_units: 10_000,
            },
            receive: CryptoAsset::Token { mint: usdc_mint },
        },
    })
    .await?;
```

</CodeGroup>

Give the returned launch URL only to the customer who owns the order. It is a private checkout session, not a loggable transaction identifier.

## Flow

```text
Quote
  └─ Select route
      └─ Create checkout
          └─ Settle
```

## Input

| Operation | Input | Requirement |
| :--- | :--- | :--- |
| Options / quote / create | `configurationId`, `environment` | Provider configuration and `sandbox` or `production`. Rust supplies `RampConfig` at construction; existing-order reads may use a client without it. |
| Quote | `location`, `order` | Country plus subdivision when needed. Buy: fiat spend and crypto receive. Sell: crypto amount and fiat receive currency. |
| Amounts | `minorUnits`, `baseUnits` | Fiat minor units (USD cents) and crypto base units. Use the returned currency exponent and asset decimals. TypeScript supports exact decimal strings/bigint; Rust uses `u64`. |
| Assets | `type`, optional `mint` | Native SOL is `{ type: "sol" }`; a token is `{ type: "token", mint }`. Python uses `NativeSolAsset` or `SplTokenAsset`. |
| Create | `requestId`, `context`, `route`, `order` | Persist one request ID per order attempt. Context contains customer ID, wallet config, location, and network. Reuse identical input on retries. |

## Output

| Operation | Field | Meaning |
| :--- | :--- | :--- |
| Quote | `route`, `details` | Provider/payment method plus buy/sell priced amounts, fee, and exchange rate. |
| Order | `id`, `type`, `status`, `createdAt`, `updatedAt`, `quote`, optional `launchUrl` | Stored checkout with its current priced amounts and lifecycle status. |

Use [order status](/query/ramp#get-order-status) to follow settlement. Quotes are re-priced at order creation. Python uses snake_case; Rust returns native typed variants.

## Errors

| Error | Meaning |
| :--- | :--- |
| Invalid configuration or amount | Configuration, environment, asset, amount scale, or location is invalid for the request. |
| Idempotency conflict | A saved request ID was reused with different creation input. |
| Provider or network failure | The provider, RPC, or transfer confirmation is unavailable; preserve attempt identifiers and signed bytes. |
