TypeScript, Python, and Rust expose a prepare-first server model. Choose the
language that owns your trusted application runtime.

## TypeScript

```typescript
import { SwigClient } from '@swig-wallet/developer-sdk';

const swig = new SwigClient({
  apiKey: process.env.SWIG_API_KEY!,
  network: 'devnet',
});
```

Install from npm with `bun add @swig-wallet/developer-sdk`. Import the API-key
client from the package root. Application-owned signing helpers are available
from `@swig-wallet/developer-sdk/signers`.

## Python

```python
import os

from swig_developer_sdk import SwigClient

swig = SwigClient(
    api_key=os.environ["SWIG_API_KEY"],
    network="devnet",
)
```

Install from PyPI with `pip install swig-developer-sdk`. Python exposes signing
helpers from the package root.

## Rust

```rust
use std::env;
use swig_developer_sdk::{ClientConfig, Network, PaymasterClient, WalletClient};

let config = ClientConfig::new(env::var("SWIG_API_KEY")?, Network::Devnet);
let wallet = WalletClient::new(config.clone())?;
let paymaster = PaymasterClient::new(config.clone())?;
```

Install from crates.io with `cargo add swig-developer-sdk@0.1.0`.
Requires Rust 1.87 or later. In `Cargo.toml`, set `package.rust-version` to
`"1.87"` and `workspace.resolver` to `"3"` for compatible dependency resolution.
Commit `Cargo.lock` and add the crates imported by your chosen examples.

Reuse the clients and run task snippets in an async, `Result`-returning
function with a runtime such as Tokio. Rust uses native Solana `Pubkey`
addresses and `VersionedTransaction` values.

The network comes from `ClientConfig`. Use `Network::Mainnet` for mainnet
operations and the same network for your confirmation RPC.
Authorize operations before signing. See [Signers](/developer-sdk/signers)
for local signing and [Ramp](/developer-sdk/ramp#required-configuration)
for Ramp client configuration.

## Comparison

| Capability | TypeScript | Python | Rust |
| :--- | :--- | :--- | :--- |
| Wallet preparation | yes | yes | `WalletClient` |
| Wallet reads | yes | yes | `WalletClient` |
| Ramp | yes | yes | `RampClient` |
| Custom transactions | yes | yes | native `Instruction` inputs |
| Sponsorship | yes | yes | `PaymasterClient` |
| Local signing | `/signers` callbacks | package-root callbacks | native keys and signing traits |

The task pages describe supported operations and language-specific limits.
Rust has no hosted guardian-recovery or rent-claimer methods.
Your application owns its HTTP routes, authentication, authorization,
validation, and response format.
