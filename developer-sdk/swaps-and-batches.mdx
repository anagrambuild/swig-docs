Prepare swaps or group SOL and token transfers in one request.
Amounts use lamports or the token mint's smallest units.

## Swaps

<CodeGroup>

```typescript TypeScript
const preparedSwap = await wallet.swap.jupiter({
  feePayer,
  inputMint,
  outputMint,
  amount: 10_000n,
  slippageBps: 100,
  destinationAccount,
  wrapAndUnwrapSol: true,
});
```

```python Python
prepared_swap = await wallet.swap.jupiter(
    fee_payer=fee_payer,
    input_mint=input_mint,
    output_mint=output_mint,
    amount=10_000,
    slippage_bps=100,
    destination_account=destination_account,
    wrap_and_unwrap_sol=True,
)
```

```rust Rust
use swig_developer_sdk::{PrepareSwapArgs, SwapOptions};

let prepared_swap = wallet
    .prepare_swap(PrepareSwapArgs {
        swig_config_address,
        fee_payer,
        requester_authority: requester_authority.clone(),
        input_mint,
        output_mint,
        amount: 10_000,
        options: Some(SwapOptions {
            slippage_bps: Some(100),
            destination_owner: Some(destination_owner),
            wrap_and_unwrap_sol: Some(true),
            ..SwapOptions::default()
        }),
    })
    .await?;
```

</CodeGroup>

`destinationAccount` is the recipient owner. The backend resolves the output
ATA for SPL outputs or the native destination for unwrapped SOL.

Rust accepts Ed25519 and secp256r1 requesters. Use a positive amount and a
compute-unit price percentile no greater than 10,000 basis points. Optional
settings include tips, maximum accounts, and blockhash expiry slots.

## Grouped operations

Prepare several SOL and token transfers in one request. All three SDKs send
this request to `POST /transaction/prepare/batch`.

<CodeGroup>

```typescript TypeScript
const prepared = await wallet.prepare({
  feePayer,
  operations: [
    {
      type: 'transferSol',
      destination,
      amount: 1_000_000n,
    },
    {
      type: 'transferToken',
      mint,
      destinationOwner,
      amount: 10_000n,
    },
  ],
});
```

```python Python
from swig_developer_sdk import TransferSolOperation, TransferTokenOperation

prepared = await wallet.prepare(
    fee_payer=fee_payer,
    operations=(
        TransferSolOperation(
            destination=destination,
            amount=1_000_000,
        ),
        TransferTokenOperation(
            mint=mint,
            destination_owner=destination_owner,
            amount=10_000,
        ),
    ),
)
```

```rust Rust
use swig_developer_sdk::{PrepareOperation, PrepareTransfersArgs};

let prepared = wallet
    .prepare_transfers(PrepareTransfersArgs {
        swig_config_address,
        fee_payer,
        requester_authority: requester_authority.clone(),
        operations: vec![
            PrepareOperation::TransferSol {
                destination,
                amount: 1_000_000,
            },
            PrepareOperation::TransferToken {
                mint,
                destination_owner,
                amount: 10_000,
            },
        ],
    })
    .await?;
```

</CodeGroup>

Rust accepts Ed25519, secp256r1, and ParticipantSet requesters. Supply at least
one operation with positive amounts.

Rust accepts a batch response containing exactly one transaction, even if the
request includes several operations.

Continue to [Signers](/developer-sdk/signers) and
[Sponsor & Submit](/developer-sdk/sponsor-and-submit).

## When to use this page

Use swaps to exchange one asset for another.

Use grouped operations when:

- you want the backend to return one ordered plan
- your app already knows several actions should happen together
- you want one preparation response instead of several separate ones
