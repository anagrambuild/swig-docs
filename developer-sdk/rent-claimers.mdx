## Introduction

The rent claimer is the recipient configured to receive reclaimed rent from a
V2 Swig wallet. Set it when your application needs an explicit rent recipient,
including a sponsor that funds account creation.

The TypeScript SDK supports reading the recipient and preparing its one-time
setter. The backend checks finalized chain state. Python and Rust do not
currently expose this hosted operation.

## SDK examples

Use the configured `swig` client and public address strings.

### Get the rent claimer

Inspect the configured recipient before preparing its one-time setter.

<CodeGroup>

```typescript TypeScript
const wallet = swig.wallets.use(swigConfigAddress, {
  requesterAuthority: { ed25519: { publicKey: requesterPublicKey } },
});
const recipient = await wallet.getRentClaimer();
```

</CodeGroup>

### Set the rent claimer

Prepare the recipient once. Sign with the requester and fee payer, submit, then wait for finality.

<CodeGroup>

```typescript TypeScript
const prepared = await wallet.setRentClaimer({
  feePayer,
  rentClaimer: rentClaimerPublicKey,
});
```

</CodeGroup>

### Confirm the recipient

After the setter reaches finality, fetch the recipient again.

<CodeGroup>

```typescript TypeScript
const confirmedRecipient = await wallet.getRentClaimer();
if (confirmedRecipient !== rentClaimerPublicKey) {
  throw new Error('Confirmed rent claimer differs from the requested recipient');
}
```

</CodeGroup>

Preparation changes no chain state. Concurrent preparations may succeed, but
only the first valid setter can land. The setter is not automatically retried.

## Input

| Operation | Parameter | Description |
| :--- | :--- | :--- |
| Both | Wallet config address and network | Use a configured wallet handle on `mainnet` or `devnet` |
| Set | `requesterAuthority` | Direct Ed25519 role with `All` or `CloseSwigAuthority`; `ManageAuthority` alone is insufficient |
| Set | `feePayer` | Public key paying the transaction fee |
| Set | `rentClaimer` | Recipient public key; cannot be zero, the Swig config, or its wallet-address PDA |

The recipient can be set only once, including when a second request names the
same recipient. Session, passkey, EVM, and ParticipantSet requesters are unsupported.

## Output

| Read result | Meaning |
| :--- | :--- |
| Public-key string | Configured rent recipient |
| `null` | Valid config with no recipient set |

## Errors

| Error | Meaning |
| :--- | :--- |
| Recipient already set | The on-chain recipient cannot be changed, even to the same key. Read the current recipient and use that confirmed value. |
| Requester not allowed | The setter requires direct Ed25519 with All or CloseSwigAuthority. Choose an eligible role; ManageAuthority alone is insufficient. |
| Invalid recipient | The address is zero, the Swig config, or its wallet-address PDA. Supply a valid separate rent-recipient account. |
| Account read failed | State is missing, malformed, unsupported, or unavailable. Check the config and network. Only a valid unset config returns null. |
