The Swig Developer SDK is the hosted wallet SDK for TypeScript and Python.

Your server keeps the API key and prepares wallet operations. Your client signs
only the prepared transactions it is responsible for. Your app submits them.

## Install

<Tabs>

<Tab title="TypeScript">

```bash
bun add @swig-wallet/developer-sdk
```

Package `@swig-wallet/developer-sdk`, version `0.8.0`.

</Tab>

<Tab title="Python">

```bash
pip install swig-developer-sdk
```

Package `swig-developer-sdk`, version `0.8.0`.

</Tab>

</Tabs>

Both packages live in
[anagrambuild/swig-developer-sdk](https://github.com/anagrambuild/swig-developer-sdk)
and default to the public API base URL `https://api.onswig.com`.

## What you can build

- create wallets from a backend route
- prepare transfers, swaps, and grouped wallet operations
- build a transaction from custom Solana instructions
- read balances, token activity, and wallet roles
- move money in and out through the fiat on-ramp and off-ramp
- submit signed transactions through Swig's paymaster, individually or as a
  bundle
- expose preparation and read routes through Next.js, NestJS, a Python proxy
  handler, or your own backend routes; keep sponsorship in server-owned code

## Use this SDK when

- your backend should keep the Swig API key
- your client should only sign prepared transactions
- you want hosted wallet creation, movement, reads, or sponsored submission
- you want framework route helpers instead of wiring each endpoint by hand

## Three ways to integrate

- use the server SDK directly
- use a built-in TypeScript framework helper or the Python proxy handler
- use the browser client against your own proxy routes

## Choose the matching SDK surface

- Use `@swig-wallet/developer-sdk` or `swig-developer-sdk` for hosted wallet
  preparation, and keep the API key on the server.
- Use `@swig-wallet/classic`, `@swig-wallet/kit`, or `swig-sdk` for direct
  protocol integration.
- See [Legacy & Raw APIs](/developer-sdk/portal-clients) if you are still on
  `@swig-wallet/developer` or `@swig-wallet/api`.
