---
title: "Secp256r1"
description: "Use a passkey or P-256 signer to authorize a Solana wallet."
---

Use r1 for passkeys and other P-256 signers. Register the public key on a role,
then give the SDK a signing callback when preparing an operation. A separate
Solana payer signs and pays for the transaction.

## Register a passkey

Your passkey registration flow supplies the credential ID and its **33-byte
compressed P-256 public key**. A credential ID or a complete WebAuthn
registration response is not the public key.

```typescript
import {
  createSecp256r1AuthorityInfo,
  getSecp256r1WebAuthnSigningFn,
} from "@swig-wallet/classic";

function passkeyAuthority(
  compressedPublicKey: Uint8Array,
  credentialId: ArrayBuffer,
  rpId: string,
) {
  const authorityInfo = createSecp256r1AuthorityInfo(compressedPublicKey);
  const signingFn = getSecp256r1WebAuthnSigningFn({
    rpId,
    allowCredentials: [{ id: credentialId, type: "public-key" }],
    userVerification: "required",
  });
  return { authorityInfo, signingFn };
}
```

Pass `authorityInfo` to [create a wallet](/solana/create-wallet) or
[add a role](/solana/add-role). Store the public key and credential ID so the
application can select the same credential later.

## Authorize an operation

Pass `signingFn`, `currentSlot: BigInt(await connection.getSlot())`, and the
Solana payer's public key to the instruction builder. The callback requests a
passkey assertion for the SDK's challenge. Submit every returned instruction
in order, including signature verification.

See [Signing](/solana/transactions/signing#r1-and-k1-signers) for the common
builder call. Initiate passkey approval from a user action and handle
cancellation before submitting a transaction.

For an application that already holds a software P-256 key,
`getSigningFnForSecp256r1PrivateKey(privateKey)` provides a signing callback.
Passkeys keep the private key in the authenticator; use the WebAuthn callback
for that flow.

To avoid a passkey prompt for every operation, grant a limited
[session](/solana/authorities/sessions).
