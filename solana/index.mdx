Build and sign Solana wallet transactions directly using your own RPC
connection and authority keys.

## Choose your language

<CodeGroup dropdown>

```bash TypeScript
npm install @swig-wallet/classic@3.0.0 @solana/web3.js@^1.98.0
```

```toml Rust
[dependencies]
swig-sdk = "3.0.0"
swig-interface = "3.0.0"
solana-sdk = "4"
```

</CodeGroup>

The TypeScript command installs Classic for Web3.js 1.x. For Solana Kit, use
`@swig-wallet/kit@3.0.0` with `@solana/kit@^2.1.0` instead. Add the Rust
dependencies to `Cargo.toml`.

## Build wallet flows

Use [reservation addresses](/solana/reservation-addresses) to derive a wallet
from an owner's public key and activate it later with a funded payer.

Explore [sessions](/examples/sessions), [passkeys](/examples/passkeys),
[swaps](/examples/swap), and [subaccounts](/examples/sub_accounts) as your
integration grows. The [Solana protocol guide](/protocol) explains the account,
permission, and execution models behind these flows.

For API-key-based transaction preparation and sponsorship from a trusted
server, use the [Developer SDK](/).
