## Choose your client

| Language and client | Swig package | Start here |
| --- | --- | --- |
| TypeScript with Solana Kit | `@swig-wallet/kit` | [TypeScript quickstart](/tutorials/typescript) |
| TypeScript with Web3.js 1.x | `@swig-wallet/classic` | [TypeScript quickstart](/tutorials/typescript) |
| Rust | `swig-sdk` | [Rust packages](/reference/rust) |

The [TypeScript package guide](/reference/typescript) also covers shared helpers
and lower-level encoding. Use [instruction builders](/reference/rust/instruction_builder)
for direct Rust instruction construction.

## Add more wallet capabilities

Explore [sessions](/examples/sessions), [passkeys](/examples/passkeys),
[swaps](/examples/swap), and [subaccounts](/examples/sub_accounts) as your
integration grows. The [Solana protocol guide](/protocol) explains the account,
permission, and execution models behind these flows.

For API-key-based transaction preparation and sponsorship from a trusted
server, use the [Developer SDK](/developer-sdk).

Building on EVM? See [Swig on EVM](/evm).
