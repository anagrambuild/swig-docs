Use the Swig Protocol SDK to add a programmable Solana wallet to your
application. Create the wallet, give each signer the access it needs, and
submit transactions through your own Solana RPC connection.

Each wallet has roles. A role pairs an **authority**—who can authorize an
operation—with **permissions**—what that authority can do. For example, an
owner can manage roles while an application's session key can spend only a
limited amount of SOL.

## Install the SDK

<CodeGroup>

```bash TypeScript
npm install @swig-wallet/classic @solana/web3.js
```

```bash Rust
cargo add swig-sdk swig-interface
```

</CodeGroup>

Choose `@swig-wallet/classic` for Web3.js 1.x or `@swig-wallet/kit` for Solana
Kit. The TypeScript examples in these pages use Classic 3.0.0. Rust applications
use `swig-sdk` for wallet operations and `swig-interface` for instruction
builders. Use an RPC connection to a cluster with a compatible Swig deployment
and a funded Solana fee payer.

## Setup

- [Create a wallet](/solana/create-wallet) with an initial authority and permissions.
- Use [counterfactual creation](/solana/reservation-addresses) to derive its address now and activate it later.

## Authorities

Choose how your users or application authorize wallet operations:

- [Ed25519](/solana/authorities/ed25519) for Solana signers.
- [Secp256r1 (r1)](/solana/authorities/secp256r1) for passkeys and P-256 signers.
- [Secp256k1 (k1)](/solana/authorities/secp256k1) for Ethereum signers.
- [ProgramExec](/solana/authorities/program-exec) for authorization from another Solana program.
- [Sessions](/solana/authorities/sessions) for temporary access through an application key.

## Permissions

[Choose permissions](/solana/permissions) for spending, program access, and
role management. Then [add a role](/solana/add-role) or
[remove a role](/solana/remove-role) as access changes.

## Transactions

[Sign wallet operations](/solana/transactions/signing) with the selected role,
then [send and confirm the transaction](/solana/transactions/sending).
The SDK's instruction builders prepare instructions; your Solana client
handles transaction signatures, submission, and confirmation.

## Use cases

- [Transfers](/solana/use-cases/transfers): send SOL or tokens from the wallet.
- [Swaps](/solana/use-cases/swaps): execute a swap with the wallet as the owner.
- [Authorization locks](/solana/use-cases/authorization-locks): reserve funds, capture a payment, or release the hold.
- [Recovery](/solana/use-cases/recovery): give a guardian permission to replace a role's lost key.
