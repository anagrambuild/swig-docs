## Introduction

A policy template stores the initial authority and actions used when creating a
wallet. Use it when your application creates many wallets with the same setup.
The Developer Portal calls this **Wallet templates**.

A template is saved configuration. Editing it does not change permissions on
an existing wallet; use [Role](/developer-sdk/add-roles-and-permissions) for that.

## Input

| Field | Required | Description |
| :--- | :--- | :--- |
| Name | Yes | Identifies the template |
| Description | No | Explains its purpose |
| Initial authority | Yes, now or at wallet creation | Choose the public-key type; save a key or let the application supply it later |
| Additional user | No | Public key and at least one allowed action; provision this role separately after wallet creation |

The portal gives the initial user full root access (`All`). Its form does not
provide an initial-user spending-limit editor. Additional users saved in the
template are **not automatically added** by Developer SDK wallet creation.

Open **Wallet templates** in the [Developer Portal](https://dashboard.onswig.com),
select **New template**, enter the fields above, and save the policy ID.
Recovery-guardian setup in that form is currently unavailable; see
[Guardian recovery](/developer-sdk/use-cases/guardian-recovery).

## SDK example

Template creation is a portal action. Use the saved policy ID with the SDK to
prepare a wallet. This example assumes the template asks for an Ed25519 initial
user. Omit that authority when the template already supplies it.

<CodeGroup>
```typescript TypeScript
const created = await swig.wallets.create({
  feePayer,
  policyId,
  initialUser: { ed25519: { publicKey: userPublicKey } },
});
```

```python Python
created = await swig.wallets.create(
    fee_payer=fee_payer,
    policy_id=policy_id,
    initial_user={"ed25519": {"publicKey": user_public_key}},
)
```

```rust Rust
use swig_developer_sdk::{PrepareCreateWalletArgs, WalletAuthority};

let created = wallet.prepare_create_wallet(PrepareCreateWalletArgs {
    fee_payer,
    policy_id: Some(policy_id),
    initial_user: Some(WalletAuthority::Ed25519 {
        public_key: user_public_key,
    }),
}).await?;
```
</CodeGroup>

Use the clients from [Client setup](/developer-sdk/integration-paths).
[Sign and submit the creation plan](/developer-sdk/create-wallets), then add each
additional role and verify its confirmed permissions. To inspect saved template
metadata, use [Fetch template](/examples/dev-portal/fetch-policy).
