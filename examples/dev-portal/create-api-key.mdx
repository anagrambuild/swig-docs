## Introduction

An API key authenticates your server to Swig’s hosted services and attributes
usage to your organization. Use it for Developer SDK queries and preparation.
Wallet authority signatures are still required for writes.

Create a key in **API Keys** in the [Developer Portal](https://dashboard.onswig.com/).
Copy its secret when shown and store it in server configuration; keep it out of
browser bundles.

## SDK examples

### Use the key

Read the stored secret when constructing the client. Replace a revoked key in the same server configuration.

<CodeGroup>

```typescript TypeScript
import { SwigClient } from '@swig-wallet/developer-sdk';

const apiKey = process.env.SWIG_API_KEY;
if (!apiKey) throw new Error('SWIG_API_KEY is required');

const swig = new SwigClient({
  apiKey,
  network: 'devnet',
});
```

```python Python
import os

from swig_developer_sdk import SwigClient

swig = SwigClient(
    api_key=os.environ["SWIG_API_KEY"],
    network="devnet",
)
```

```rust Rust
use std::env;
use swig_developer_sdk::{ClientConfig, Network, PaymasterClient, WalletClient};

let config = ClientConfig::new(env::var("SWIG_API_KEY")?, Network::Devnet);
let wallet = WalletClient::new(config.clone())?;
let paymaster = PaymasterClient::new(config.clone())?;
```

</CodeGroup>

## Input

| Input | Requirement |
| :--- | :--- |
| Key name | A descriptive name for the server/integration. |
| Expiration | Optional expiration selected at creation; expired keys cannot authenticate. |
| `SWIG_API_KEY` | The full secret, available when the key is created. Keep it in the runtime making hosted calls. |

## Errors

| Error | Meaning |
| :--- | :--- |
| Missing key | The server configuration has no API key; client setup cannot complete. |
| Authentication failed | The key is invalid, expired, or revoked. |
| Access denied | The authenticated organization cannot access the requested wallet or resource. |
| Quota exhausted | The organization’s admission cap is reached; [Pricing & quotas](/query) defines its allowances. |
