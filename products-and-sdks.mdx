## Developer SDK

Use the hosted API to prepare transactions and read wallet state. Your
application owns authentication, authorization, signing, and confirmation.

- Start with [client setup](/developer-sdk/integration-paths) and an [API key](/examples/dev-portal/create-api-key).
- Follow [wallet creation](/developer-sdk/create-wallets), [transfers](/developer-sdk/transfers-and-swaps), and [sponsored submission](/developer-sdk/sponsor-and-submit).
- Use the [REST API reference](/developer-api) for endpoint paths and payloads.

## Solana Protocol SDK

Use the protocol directly when your application owns its RPC connection,
authority keys, instruction composition, and transaction submission.

- Start with the [Solana SDK overview](/solana).
- Choose [TypeScript packages](/reference/typescript) or [Rust packages](/reference/rust).
- Read [protocol concepts](/protocol) for accounts, permissions, sessions, and recovery.

## EVM Protocol SDK

Use the source-available SDKs with a compatible Swig deployment and your own
keys and RPC connection.

- Start with the [EVM SDK overview](/evm) and [environment setup](/evm/setup).
- Follow [wallet creation](/evm/create-wallet), [role assignment](/evm/add-role), and [transfers](/evm/send-transfer).
- Check [bundler compatibility](/evm/bundler-compatibility) before sponsoring operations.

## IdP

Authenticate users and persist a Swig session before continuing into wallet
flows. The published SDK uses TypeScript for browser and Expo / React Native apps.

- Choose an [authentication method](/idp-sdk/auth-methods).
- Follow the [browser](/idp-sdk/web-apps) or [mobile](/idp-sdk/expo-and-react-native) guide.
- Understand [sessions and security](/idp-sdk/sessions-and-security) before handing the session to your wallet layer.
