Swig IdP handles user sign-in and returns a persisted session for your wallet
integration. OAuth is available in browsers and Expo / React Native. The mobile
provider also supports email and SMS OTP.

## Choose your language

The published package is TypeScript. Choose your application platform in the
getting-started steps below.

<CodeGroup dropdown>

```bash TypeScript
npm install @swig-wallet/expo-idp-sdk
```

</CodeGroup>

Use the `/web` entry point in browsers and the mobile provider in Expo / React
Native. Follow the platform guide for its dependencies and setup.

## Get started

1. [Choose an authentication method](/idp-sdk/auth-methods).
2. [Choose your platform](/idp-sdk/web-and-mobile): [browser](/idp-sdk/web-apps) or [Expo / React Native](/idp-sdk/expo-and-react-native).
3. Complete sign-in and [persist the session](/idp-sdk/sessions-and-security).
4. Use the session in your wallet integration and configure [authority and agents](/idp-sdk/authority-and-agents).

## What you get back

Every successful auth flow ends with a persisted Swig session. The session
contains:

- `configAddress`
- `walletAddress`
- `roleId`
- `authFlow`

That session is the bridge into the next layer of the stack.
